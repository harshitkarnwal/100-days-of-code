# Days 51–97 solutions

The 47 standalone C solutions for UPES Days 51–97 (Q101–Q147), plus their README and input conventions, are packaged in [`days-51-97-solutions.tar.gz`](days-51-97-solutions.tar.gz).

Extract the archive at the repository root to get `day-51/q101.c` through `day-97/q147.c`.

All 47 programs compile cleanly with `gcc -std=c11 -Wall -Wextra -Wpedantic -Werror` and were sample-tested.
